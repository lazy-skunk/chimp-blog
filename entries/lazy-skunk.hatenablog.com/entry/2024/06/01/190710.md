<p>Tera Term のマクロで、SSH のログインを自動化してみた。複雑な処理ではないけど、実際に作って動くと結構楽しい。</p>

<pre><code>; 接続情報（例）
host = "192.0.2.1"
user_name = "guest"
password = "password"

; 接続文字列を作成
connection_info = ""
strconcat connection_info host
strconcat connection_info ":22"
strconcat connection_info " /ssh"
strconcat connection_info " /auth=password"
strconcat connection_info " /user="
strconcat connection_info user_name
strconcat connection_info " /passwd="
strconcat connection_info password

; 接続
connect connection_info</code></pre>

<p>接続先、ユーザー名、パスワードを使って接続文字列を作り、<code>connect</code> に渡している。上の値は例なので、使うときは自分の接続先に置き換える。</p>

<p>公式の説明が丁寧で、何を指定すればよいのか分かりやすかった。鍵認証も選べるし、地味に面倒なログイン作業をクリックで始められるようになったのは嬉しい。</p>

<p>文字列の結合が <code>strconcat</code> なのは想定外だったけど、そこは慣れの問題かな。</p>

<p>今のところ自動化したい業務がないので出番はなさそう。でも少しできることの幅が広がった気がする。何かの機会があれば手を挙げたいなあ。</p>
