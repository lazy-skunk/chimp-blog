<p>VS Code で pytest をデバッグしていたら、ブレイクポイントで止まらなくなった。自分の環境ではデバッグ時にカバレッジの測定を無効にしたら止まるようになった。しばらくハマってしまったので残しておこう。</p>

<h3>カバレッジ測定との競合</h3>

<p>調べてみると、デバッガーとカバレッジ測定が使うトレース処理が競合し、ブレイクポイントに影響することがあるらしい。pytest-cov が入っているだけで必ず起きるわけではないらしく、測定が有効になっているかや環境にもよるみたい。</p>

<p><a href="https://code.visualstudio.com/docs/python/testing#_pytest-configuration-settings" target="_blank">Testing Python in Visual Studio Code</a></p>

<p><a href="https://github.com/microsoft/vscode-python/issues/693" target="_blank">Debugger doesn't stop at breakpoints with pytest if pytest-cov is used · Issue #693 · microsoft/vscode-python · GitHub</a></p>

<h3>デバッグ時は --no-cov を指定する</h3>

<p><code>launch.json</code> のテスト用設定で、<code>PYTEST_ADDOPTS</code> に <code>--no-cov</code> を指定した。</p>

<pre><code>{
  &quot;version&quot;: &quot;0.2.0&quot;,
  &quot;configurations&quot;: [
   {
      // Disable coverage to ensure breakpoints are enabled during debugging.
      &quot;name&quot;: &quot;Python Debugger: Debug Tests&quot;,
      &quot;type&quot;: &quot;debugpy&quot;,
      &quot;request&quot;: &quot;launch&quot;,
      &quot;purpose&quot;: [&quot;debug-test&quot;],
      &quot;console&quot;: &quot;internalConsole&quot;,
      &quot;justMyCode&quot;: false,
      &quot;env&quot;: {
        &quot;PYTEST_ADDOPTS&quot;: &quot;--no-cov&quot;
      }
    }
  ]
}</code></pre>

<p>ちなみに <code>settings.json</code> の pytest に関する部分はこんな感じ。</p>

<pre><code>{
    // Omitted
    &quot;python.testing.pytestEnabled&quot;: true,
    // Omitted
}</code></pre>

<p><code>pyproject.toml</code> では、通常のテスト実行時にカバレッジを測定するオプションを指定していた。</p>

<pre><code># Omitted
[tool.pytest.ini_options]
addopts = &quot;--cov=src --cov-config=.coveragerc --cov-report=html&quot;
testpaths = [&quot;tests&quot;]
# Omitted</code></pre>

<p>普段はカバレッジを取り、デバッグするときは測定を無効にするという使い分けになる。</p>

<p>最初は Docker コンテナ上で開発していることが原因かと思っていたんだけど、そこではなかった。</p>
