<p>VS Code から GitHub にリポジトリーを作成しようとして、次のエラーが出た。</p>

<pre><code>github repository already exists.</code></pre>

<p>この環境では GitHub 側でリポジトリーを作成してから、ローカルの接続先を設定して push すると進められた。</p>

<h3>行った操作</h3>

<p>GitHub 側に新しいリポジトリーを作り、ローカルで次のコマンドを実行した。</p>

<pre><code>git remote add origin https://github.com/USER/REPOSITORY.git
git push -u origin main</code></pre>

<p><code>USER</code> と <code>REPOSITORY</code> は自分のものに置き換える。また <code>git remote add</code> は接続先を追加するコマンドなので、すでに <code>origin</code> がある場合には使えない。</p>

<p>既存の接続先を確認し、必要なら URL を変更する。</p>

<pre><code>git remote -v
git remote set-url origin https://github.com/USER/REPOSITORY.git</code></pre>

<h3>原因はまだ推測</h3>

<p>エラーが出た時点では、その名前のリポジトリーはリモート側に見当たらなかった。ただ、過去に同じ名前で作成したことはあるので、そのときの情報が何か関係していたのかなと推測している。</p>

<p>ただ、原因そのものはまだ分からない。確認できたのは GitHub 側で作成し、Git のコマンドで接続先を指定すると push できたというところまで。</p>

<p>とりあえず進められたのはよかったけど、エラーメッセージだけでは何が残っているのか分かりづらかったなあ。</p>
