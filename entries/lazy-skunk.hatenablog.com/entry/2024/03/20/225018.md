<h3>バックグラウンドで実行する -d</h3>

<pre><code>docker run -dp 127.0.0.1:3000:3000 getting-started</code></pre>

<p><code>-d</code> は <code>--detach</code> の略でコンテナをバックグラウンドで実行するためのオプション。<code>-p</code> はポートを公開するための指定で、この例ではホストの <code>127.0.0.1:3000</code> をコンテナの <code>3000</code> 番ポートにつないでいる。</p>

<p><code>-d</code> を付けずに実行したときは次のようになった。</p>

<pre><code>PS C:\Users\UserName\Workspace\docker\getting-started\app&gt; docker run -p 127.0.0.1:3000:3000 getting-started
Using sqlite database at /etc/todos/todo.db
Listening on port 3000</code></pre>

<p>当然フォアグラウンドでの動作となりますね。プロンプトが一つ塞がるのは嫌なので基本的に <code>-d</code> は付けたいなあ。</p>
