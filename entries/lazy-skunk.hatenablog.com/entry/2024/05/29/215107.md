<p>Bag of Words（BoW）とコサイン類似度を最近知って、実際に動かしてみた。こういう比べ方があるんだなあ。</p>

<p><code>CountVectorizer</code> で文章を単語の出現回数に変換し、そのベクトル同士のコサイン類似度を求めている。元の文章、単語ごとの回数、類似度を表にすると、何を比べているのかを追いやすかった。</p>

<pre><code>from sklearn.feature_extraction.text import CountVectorizer
from sklearn.metrics.pairwise import cosine_similarity
import pandas


sample_log1 = &quot;This is the first log&quot;
sample_log2 = &quot;This is the second log&quot;
sample_log3 = &quot;Pen pineapple apple pen&quot;
sample_logs = [sample_log1, sample_log2, sample_log3]

count_vectorizer = CountVectorizer()
bag_of_words_matrix = count_vectorizer.fit_transform(sample_logs)
feature_names = count_vectorizer.get_feature_names_out()
print(&quot;###############################################################################&quot;)
print(feature_names)
print(&quot;###############################################################################&quot;)

bag_of_words_data_frame = pandas.DataFrame(
    bag_of_words_matrix.toarray(), columns=feature_names, index=[&quot;log1&quot;, &quot;log2&quot;, &quot;log3&quot;]
)
print(bag_of_words_data_frame)
print(&quot;###############################################################################&quot;)

cosine_similarity_matrix = cosine_similarity(bag_of_words_matrix)
similarity_data_frame = pandas.DataFrame(
    cosine_similarity_matrix,
    index=[&quot;log1&quot;, &quot;log2&quot;, &quot;log3&quot;],
    columns=[&quot;log1&quot;, &quot;log2&quot;, &quot;log3&quot;],
)

print(similarity_data_frame)
print(&quot;###############################################################################&quot;)</code></pre>

<p>最初の二つは共通する単語が多く、三つ目は内容の違う文章にしている。算出した類似度をもとに似たログをまとめたり傾向を調べたりできそう。便利だなあ。</p>

<p>ただ、単語の回数を使う方法なので、文章の意味をそのまま理解して比べているわけではない。</p>
