<p>最大値を探すとき、初期値には <code>0</code> や <code>None</code> 以外に負の無限大を表す <code>-float("inf")</code> も使えるって話。</p>

<p><code>inf</code> は infinity。<code>float("inf")</code> で正の無限大を作り、先頭の <code>-</code> で負の無限大にしている。</p>

<p>実務で使うかどうかは別だけど、こういう選択肢を持っておいて損はないと思う。さして得もないかもしれないけど…。</p>

<h3>3番目に大きい値を探す例</h3>

<p>空ではない整数の配列から、重複を除いた3番目の最大値を返す関数を考える。異なる値が3つなければ、最大値を返すことにする。</p>

<pre><code>def third_max(nums: list[int]) -&gt; int:
    first_max = second_max = third_max = -float(&quot;inf&quot;)

    for num in nums:
        if num &gt; first_max:
            third_max = second_max
            second_max = first_max
            first_max = num
        elif first_max &gt; num &gt; second_max:
            third_max = second_max
            second_max = num
        elif second_max &gt; num &gt; third_max:
            third_max = num

    if third_max == -float(&quot;inf&quot;):
        return int(first_max)
    return int(third_max)</code></pre>

<p>初期値を <code>0</code> にすると、負の整数だけが渡されたときにも <code>0</code> が最大値の候補に残ってしまう。配列には含まれていないのに。負の無限大なら、どの整数よりも小さい値として比較を始められる。</p>

<p>一方、<code>None</code> は整数とそのまま大小比較できないので、使うなら未設定かどうかを判定する分岐が必要になる。最初は <code>None</code> で初期化するのは名案だと思ったんだけどな…。</p>

<p>今回は空でない配列が来る前提。</p>
