<p>カバレッジを HTML 形式で出せたらいいなと思ったので、pytest で試してみた。必要な設定を忘れないように備忘録として残しておこう。</p>

<h3>pytest-cov をインストールする</h3>

<pre><code>python -m pip install pytest-cov</code></pre>

<p><code>pytest-cov</code> は coverage.py を利用するプラグインで、必要な依存関係も一緒にインストールされる。</p>

<p>当時は通信速度制限がかかっていたので、インストール時に <code>--timeout=9999</code> を付けていた。</p>

<h3>測定するパスやパッケージを指定する</h3>

<pre><code>pytest --cov=test_target --cov-report=html</code></pre>

<p><code>--cov-report=html</code> が HTML レポートを出力する指定。<code>--cov=test_target</code> はカバレッジを測定するパスやパッケージを指定している。</p>

<p>自分の環境では <code>--cov=test2</code> として試していたが、ここは自分が測定したいコードの名前に置き換える。</p>

<p>プロジェクトのルートで <code>--cov=.</code> とすればカレントディレクトリーを測定対象として指定できる。ただし、実際に何が記録されるかは実行されたコードや coverage.py の除外設定などにもよる。</p>

<p><code>--cov=</code> のように値を空にすると、このオプションによる対象の絞り込みを行わない。とはいえ試したときはすべて記録されているようには見えなかった。使い方が悪いのか？</p>

<h3>毎回コマンドを打つのか問題</h3>

<p>さて、コマンドで実行する方法は分かったが、実際にテストするたびに長いオプションを打つのは面倒だなと思う。</p>

<p>設定ファイルにまとめる方法や、VS Code から実行する方法も学んだ方がよさそう。ポチポチしたら対象のカバレッジを出力できれば嬉しいんだけどなあ。</p>
