<p>この記事で紹介されていた dust が気になって、インストールしてみた話。</p>

<h3>使っていた環境</h3>

<pre><code>FROM python:3.13-slim</code></pre>

<p>ベースにしていたのはこの Python イメージ。作業時の OS は Debian だった。</p>

<pre><code>root@c5436136697e:/workspace# cat /etc/os-release
NAME=&quot;Debian GNU/Linux&quot;
root@c5436136697e:/workspace#</code></pre>

<h3>インストールに使うコマンド</h3>

<p>この環境では Cargo でソースからビルドした。必要だったものも含めて、コマンドをまとめるとこんな感じ。</p>

<pre><code>apt-get update
apt-get install -y build-essential curl
curl https://sh.rustup.rs -sSf | sh
. &quot;$HOME/.cargo/env&quot;
cargo install du-dust</code></pre>

<p>Rust のインストール後、同じシェルから <code>cargo</code> が見つからない場合は、Cargo の環境設定を読み込む。別のシェルを開き直してもよい。</p>

<h3>途中で引っかかったこと</h3>

<p>最初は <code>apt-get install dust</code> を試したけど、当時の環境では見つからなかった。</p>

<p>次に <code>cargo install du-dust</code> を試したものの、そもそも Cargo が入っていなかった。Rust を入れて再挑戦すると、今度は <code>linker &#96;cc&#96; not found</code>。一つ解決するとまた次のエラーが出てくる…。</p>

<p>自分の環境では <code>build-essential</code> を入れて、ビルドに必要なツールを用意すると進められた。ビルド用のツールも必要だったのか。以下はそのときの作業ログの抜粋。</p>

<pre><code># そんなものはないと…。
root@c5436136697e:/workspace# apt-get install dust
Reading package lists... Done
Building dependency tree... Done
Reading state information... Done
E: Unable to locate package dust
root@c5436136697e:/workspace#

# https://github.com/bootandy/dust?tab=readme-ov-file#install
# どうやら apt-get ではダメだとわかる。

# インストールを試みるも cargo が入っていなかった。（エラーは残っていない、プロンプトを閉じたので）
cargo install du-dust

# https://doc.rust-lang.org/cargo/getting-started/installation.html
# cargo を入れてみる。
curl https://sh.rustup.rs -sSf | sh

# いざインストール！するもエラー…。
root@c5436136697e:/workspace# cargo install du-dust

～省略～

   Compiling rayon-core v1.13.0
error: linker `cc` not found
  |
  = note: No such file or directory (os error 2)

～省略～

root@c5436136697e:/workspace#

# build-essential が必要だった！
apt-get update
apt-get install -y build-essential

# 再挑戦！
root@c5436136697e:/workspace# cargo install du-dust

<p>知ったところであまり意味がないと言えばそうだけど、こういう名前の由来は大事にしたい思いがある。</p>
