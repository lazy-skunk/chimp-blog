<p>ジェネレーター関数へ Step Into しようとしたのに、中の処理へ入らなかった。理由は呼び出しただけでは関数本体の実行が始まらないからだった。</p>

<h3>呼び出しと実行開始のタイミングが違う</h3>

<p>次は CSV ファイルを読み込み、空でないデータフレームを順に返す例。動かすには pandas と <code>data</code> ディレクトリー内の CSV ファイルが必要になる。</p>

<pre><code>from collections.abc import Generator
from pathlib import Path

import pandas as pd

_BASE_DIR = Path(__file__).parent
_DATA_DIR = _BASE_DIR / &quot;data&quot;


def load_phonetic_dfs(directory: Path) -&gt; Generator[pd.DataFrame, None, None]:
    for csv_file_path in directory.glob(&quot;*.csv&quot;):
        df = pd.read_csv(csv_file_path)
        if df.empty:
            print(&quot;0件&quot;)
            continue
        yield df


def _print_with_for(directory: Path) -&gt; None:
    for df in load_phonetic_dfs(directory):
        print(df.head())


def _print_with_next(directory: Path) -&gt; None:
    frames = load_phonetic_dfs(directory)

    while True:
        try:
            df = next(frames)
        except StopIteration:
            print(&quot;StopIteration 発生時の例外処理を行う。&quot;)
            break
        print(df.head())


if __name__ == &quot;__main__&quot;:
    _print_with_for(_DATA_DIR)
    print(&quot;==========&quot;)
    _print_with_next(_DATA_DIR)</code></pre>

<p><code>_print_with_next</code> の <code>frames = load_phonetic_dfs(directory)</code> にブレイクポイントを置き、Step Into しようとしたら素通りした。</p>

<p>その時点ではジェネレーターオブジェクトが返ってきているだけ。関数本体の実行が始まるのは <code>next(frames)</code> などで次の値を要求したとき。呼んだ時点で中に入るわけじゃないのか。その後は <code>yield</code> まで進み、次に値を要求すると、その続きから再開する。</p>

<h3>for で使う場合と next で使う場合</h3>

<p><code>for</code> なら次の値を取り出す処理も、値がなくなったときの終了も扱ってくれる。<code>next</code> で自分から取り出す場合は、最後に <code>StopIteration</code> が発生することも考える必要がある。</p>

<p>上のコードは動作確認後に整理したものなので、少し伝えにくい。デバッグしながら作っていたときは、まだ次の値を取り出す処理を書いていなかった。呼び出せばそのまま中へ入ると思っていたんだよなあ。</p>

<p>細かく制御しなければならない理由がないなら、<code>_print_with_for</code> のように素直に <code>for</code> で使う方が分かりやすそうだなあと思う。</p>
